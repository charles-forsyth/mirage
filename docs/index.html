Mirage: AI Video & Audio Experience Orchestrator

An AI video and audio experience orchestrator coordinating image generation (Lumina), Veo 3.1 video (Vidius), Gemini 3.8 voices (Gen-TTS), and Lyria music (Gen-Music), mixed and mastered with ffmpeg.

uv tool install --python 3.12 git+https://github.com/charles-forsyth/mirage.git
View Repository Explore Terminal Output

Key Capabilities

Designed and tuned for modern terminal workflows and automated pipelines.

✨

Hybrid Presenter Videos

Low-cost presenter videos combining narrator voice, Ken Burns motion stills, code screens, and Veo b-roll hero shots.

✨

Atmospheric Weather Shows

Generate standalone HTML experiences with two-voice weather podcast, custom art, and background video.

✨

Deep Research Documentaries

Transform multi-source deep research into narrated 16:9 documentaries and vertical YouTube Shorts.

✨

Character Library & Stories

Manage character personas and direct seamless multi-part cinematic stories with Veo.

Terminal Showcase

Real, unmodified terminal outputs captured directly from the CLI engine.

mirage --help

Usage Examples

Quick command recipes for terminal operations.

Hybrid Presenter Video

Create presenter tutorial video with voice and hero clips:

mirage hybrid "An introduction to quantum computing" --tutorial

Atmospheric Weather Show

Generate two-speaker weather podcast with art:

mirage weather --tier lite

Character Library

Inspect available character personas:

mirage character list

News Video Short

Create vertical 9:16 news short with music:

mirage news-short "Breakthrough in clean energy"
